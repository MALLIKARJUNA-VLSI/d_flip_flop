# D-Flip-Flop (Active-Low Async Reset)

**Description:**
RTL implementation of a positive edge-triggered D-Flip-Flop written in Verilog. The memory element captures data precisely on the rising clock edge while supporting an instantaneous, active-low asynchronous reset that overrides the clock.

**Verification:**
Includes a self-checking testbench (`d_flip_flop_tb.v`) compiled and simulated using Icarus Verilog.
